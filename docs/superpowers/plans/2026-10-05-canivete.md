# Canivete Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construir a plataforma Canivete (hub público de ferramentas com registro de módulos) e o primeiro módulo, `raffle` (sorteador de nomes com link verificável).

**Architecture:** App Vue 3 estático. Cada ferramenta é uma pasta em `src/modules/<id>/` com um `manifest.ts`; o `core` descobre os manifests via `import.meta.glob` e gera router, home e busca. O Appwrite é um serviço lazy, usado só pelos módulos com `usesBackend: true`. A lógica do sorteador é pura e separada da UI.

**Tech Stack:** Vue 3, Vite, TypeScript, Vue Router, Tailwind CSS v4, shadcn-vue, `@lucide/vue`, Appwrite Web SDK, Vitest, `@vue/test-utils`, jsdom.

**Spec:** `docs/superpowers/specs/2026-10-05-canivete-design.md`

## Global Constraints

- Identificadores (pastas, arquivos, variáveis, funções, classes, tipos, rotas, chaves de dados) em **inglês**.
- Textos de interface, mensagens de erro, comentários e blocos JSDoc em **português (pt-BR)**.
- Estilo 100% **Tailwind v4** em classes utilitárias. `style` inline só para valores dinâmicos. Sem `<style>` em componentes. CSS próprio apenas nas variáveis de tema geradas pelo shadcn-vue.
- Componentes de UI: shadcn-vue em `src/components/ui/`. Ícones: `@lucide/vue` (nenhum import de `lucide-vue-next` pode sobrar).
- Vue: Composition API com `<script setup lang="ts">`.
- Um módulo nunca importa de outro módulo; o `core` nunca importa de um módulo específico.
- Limites do sorteador: 1.000 nomes, 100 caracteres por nome.
- Sorteio com `crypto.getRandomValues` e rejeição (sem viés). Hash: SHA-256 hexadecimal (64 caracteres) sobre JSON com chaves na ordem `participants`, `winners`, `drawnAt`.
- Coleção Appwrite `raffles`: leitura e criação para `any`; sem update nem delete.
- Mensagens de commit terminam com a linha `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
- Idioma do site: apenas português; sem i18n.

## Review Focus

Entradas e condições que a spec implica mas que nenhuma tarefa exercitaria sem teste explícito, da mais provável para a menos provável:

1. Texto colado com quebras de linha do Windows (`\r\n`), linhas só com espaços e entrada vazia: o sorteio fica bloqueado com mensagem em português, sem exceção. (Task 6, Task 10)
2. Nomes duplicados com diferença de maiúsculas ("Ana" e "ana"): são sinalizados, nunca removidos em silêncio. No modo sem repetição, cada vencedor remove apenas uma ocorrência. (Task 6, Task 10)
3. Pedir mais vencedores do que nomes restantes (inclusive depois de rodadas sem repetição, ou com o campo numérico vazio): mensagem "Restam apenas N nomes", sem erro não tratado. (Task 7, Task 10)
4. Nomes com aspas, barras invertidas, emoji e acentos: o hash é estável e continua verificando depois de gravar e ler do Appwrite. (Task 8)
5. Link com id inexistente, Appwrite fora do ar ou variáveis de ambiente ausentes: telas amigáveis em português, nunca página em branco. (Task 5, Task 9, Task 12)

`src/core/modules/registry.ts`:
```ts
import type { ToolManifest } from './types'

type ManifestModules = Record<string, { default: ToolManifest }>

/**
 * Valida os manifests encontrados e devolve a lista de ferramentas ordenada por título.
 * Lança erro em português se algum manifest estiver inválido.
 */
export function buildRegistry(modules: ManifestModules): ToolManifest[] {
  const seenIds = new Set<string>()
  const result: ToolManifest[] = []

  for (const [path, mod] of Object.entries(modules)) {
    const manifest = mod.default
    if (!manifest || !manifest.id) {
      throw new Error(`Manifest inválido em ${path}: falta o campo "id".`)
    }
    if (seenIds.has(manifest.id)) {
      throw new Error(`Id de módulo duplicado: "${manifest.id}".`)
    }
    seenIds.add(manifest.id)

    const prefix = `/${manifest.id}`
    for (const route of manifest.routes) {
      const isInsideModule = route.path === prefix || route.path.startsWith(`${prefix}/`)
      if (!isInsideModule) {
        throw new Error(
          `Rota "${route.path}" do módulo "${manifest.id}" deve começar com o prefixo "${prefix}".`,
        )
      }
    }
    result.push(manifest)
  }

  return result.sort((a, b) => a.title.localeCompare(b.title, 'pt-BR'))
}

/** Registro real: descobre todos os `src/modules/*/manifest.ts`. */
export const tools: ToolManifest[] = buildRegistry(
  import.meta.glob<{ default: ToolManifest }>('/src/modules/*/manifest.ts', { eager: true }),
)
```

```ts
import type { ToolManifest } from '@/core/modules/types'

/** Remove acentos e converte para minúsculas, para comparar textos em pt-BR. */
function normalize(text: string): string {
  return text.normalize('NFD').replace(/[̀-ͯ]/g, '').toLowerCase().trim()
}

/** Filtra as ferramentas por texto (título e descrição) e por categoria. */
export function filterTools(
  tools: ToolManifest[],
  query: string,
  category: string | null,
): ToolManifest[] {
  const q = normalize(query)
  return tools.filter((tool) => {
    if (category && tool.category !== category) return false
    if (!q) return true
    return normalize(`${tool.title} ${tool.description}`).includes(q)
  })
}
```

`src/core/theme/useTheme.ts`:
```ts
import { ref } from 'vue'

const STORAGE_KEY = 'canivete-theme'
const isDark = ref(false)

/** Lê a preferência salva; se não houver (ou o storage falhar), usa a do sistema. */
function readInitial(): boolean {
  try {
    const saved = localStorage.getItem(STORAGE_KEY)
    if (saved) return saved === 'dark'
  } catch {
    // Storage indisponível (modo privado, etc.): segue para a preferência do sistema.
  }
  return window.matchMedia('(prefers-color-scheme: dark)').matches
}

function apply(dark: boolean) {
  document.documentElement.classList.toggle('dark', dark)
}

/** Controla o tema claro/escuro e persiste a escolha. */
export function useTheme() {
  function init() {
    isDark.value = readInitial()
    apply(isDark.value)
  }

  function toggle() {
    isDark.value = !isDark.value
    apply(isDark.value)
    try {
      localStorage.setItem(STORAGE_KEY, isDark.value ? 'dark' : 'light')
    } catch {
      // Sem persistência: o tema vale só nesta sessão.
    }
  }

  return { isDark, init, toggle }
}
```

```ts
export const MAX_NAMES = 1000
export const MAX_NAME_LENGTH = 100

export interface ParsedNames {
  /** Nomes normalizados, na ordem digitada (duplicados preservados). */
  names: string[]
  /** Nomes que aparecem mais de uma vez (sem diferenciar maiúsculas), na primeira forma vista. */
  duplicates: string[]
  /** Nomes acima de MAX_NAME_LENGTH caracteres. */
  tooLong: string[]
  /** True se há mais de MAX_NAMES nomes. */
  tooMany: boolean
}

/** Converte o texto bruto (um nome por linha) em uma lista normalizada e diagnósticos. */
export function parseNames(raw: string): ParsedNames {
  const names = raw
    .split(/\r?\n/)
    .map((line) => line.trim())
    .filter((line) => line.length > 0)

  const counts = new Map<string, { first: string; count: number }>()
  for (const name of names) {
    const key = name.toLocaleLowerCase('pt-BR')
    const entry = counts.get(key)
    if (entry) entry.count += 1
    else counts.set(key, { first: name, count: 1 })
  }

  return {
    names,
    duplicates: [...counts.values()].filter((e) => e.count > 1).map((e) => e.first),
    tooLong: names.filter((name) => name.length > MAX_NAME_LENGTH),
    tooMany: names.length > MAX_NAMES,
  }
}

/** Devolve uma mensagem em português se a lista não puder ser sorteada; senão, null. */
export function validateNames(parsed: ParsedNames): string | null {
  if (parsed.names.length === 0) return 'Adicione pelo menos um nome.'
  if (parsed.tooMany) return 'O limite é de 1.000 nomes por sorteio.'
  if (parsed.tooLong.length > 0) return `Cada nome pode ter no máximo ${MAX_NAME_LENGTH} caracteres.`
  return null
}

/**
 * Remove do texto bruto uma ocorrência de cada nome informado.
 * Usado no modo "sem repetição" para tirar os vencedores da lista.
 */
export function removeNames(raw: string, toRemove: string[]): string {
  const lines = raw.split(/\r?\n/)
  for (const name of toRemove) {
    const index = lines.findIndex((line) => line.trim() === name)
    if (index !== -1) lines.splice(index, 1)
  }
  return lines.join('\n')
}
```

```ts
/** Fonte de inteiros aleatórios em [0, maxExclusive). Injetável para tornar testes determinísticos. */
export type RandomInt = (maxExclusive: number) => number

/**
 * Inteiro uniforme em [0, maxExclusive) usando crypto.getRandomValues.
 * Usa rejeição para evitar o viés do operador módulo.
 */
export function secureRandomInt(maxExclusive: number): number {
  if (!Number.isInteger(maxExclusive) || maxExclusive < 1) {
    throw new RangeError('O limite precisa ser um inteiro maior ou igual a 1.')
  }
  const range = 0x100000000
  const limit = Math.floor(range / maxExclusive) * maxExclusive
  const buffer = new Uint32Array(1)
  do {
    crypto.getRandomValues(buffer)
  } while (buffer[0] >= limit)
  return buffer[0] % maxExclusive
}

export class DrawError extends Error {
  constructor(
    public readonly code: 'EMPTY' | 'INVALID_COUNT',
    message: string,
  ) {
    super(message)
    this.name = 'DrawError'
  }
}

/**
 * Sorteia `count` vencedores com embaralhamento Fisher-Yates.
 * Cada entrada da lista é um "bilhete" independente: nomes repetidos têm mais chances.
 */
export function drawWinners(
  participants: string[],
  count: number,
  randomInt: RandomInt = secureRandomInt,
): string[] {
  if (participants.length === 0) {
    throw new DrawError('EMPTY', 'Adicione pelo menos um nome.')
  }
  if (!Number.isInteger(count) || count < 1) {
    throw new DrawError('INVALID_COUNT', 'Informe ao menos 1 vencedor.')
  }
  if (count > participants.length) {
    throw new DrawError('INVALID_COUNT', `Restam apenas ${participants.length} nomes para sortear.`)
  }

  const pool = [...participants]
  for (let i = pool.length - 1; i > 0; i--) {
    const j = randomInt(i + 1)
    ;[pool[i], pool[j]] = [pool[j], pool[i]]
  }
  return pool.slice(0, count)
}
```

```ts
}

/** SHA-256 em hexadecimal (64 caracteres) de um texto UTF-8. */
export async function sha256Hex(text: string): Promise<string> {
  const digest = await crypto.subtle.digest('SHA-256', new TextEncoder().encode(text))
  return Array.from(new Uint8Array(digest))
    .map((byte) => byte.toString(16).padStart(2, '0'))
    .join('')
}

/** Calcula o hash de um sorteio. */
export function computeHash(record: RaffleRecord): Promise<string> {
  return sha256Hex(canonicalJson(record))
}

/** Confere se o hash gravado ainda corresponde ao conteúdo do registro. */
export async function verifyRecord(record: RaffleRecord & { hash: string }): Promise<boolean> {
  return (await computeHash(record)) === record.hash
}
```

```ts
import { AppwriteConfigError } from '@/core/services/appwrite'
import { computeHash, verifyRecord, type RaffleRecord } from './verify'

export interface StoredRaffle extends RaffleRecord {
  id: string
  hash: string
}

/** Abstração de armazenamento; a implementação real usa o Appwrite. */
export interface RaffleStore {
  create(data: RaffleRecord & { hash: string }): Promise<string>
  get(id: string): Promise<StoredRaffle | null>
}

export class ShareError extends Error {
  constructor(
    public readonly code: 'NOT_FOUND' | 'NETWORK' | 'CONFIG',
    message: string,
  ) {
    super(message)
    this.name = 'ShareError'
  }
}

/** Traduz qualquer falha do armazenamento para um ShareError com mensagem em português. */
function toShareError(error: unknown): ShareError {
  if (error instanceof ShareError) return error
  if (error instanceof AppwriteConfigError) {
    return new ShareError('CONFIG', 'O compartilhamento ainda não está configurado neste site.')
  }
  return new ShareError('NETWORK', 'Não foi possível falar com o servidor. Tente novamente em instantes.')
}

/**
 * Implementação real da store, sobre o Appwrite.
 * O serviço é importado sob demanda para que o SDK só carregue quando for necessário.
 */
export async function createAppwriteStore(): Promise<RaffleStore> {
  const { ID } = await import('appwrite')
  const { getAppwrite, getAppwriteIds } = await import('@/core/services/appwrite')
  const { databases } = getAppwrite()
  const { databaseId, rafflesCollectionId } = getAppwriteIds()

  return {
    async create(data) {
      const doc = await databases.createDocument(databaseId, rafflesCollectionId, ID.unique(), data)
      return doc.$id
    },
    async get(id) {
      try {
        const doc = await databases.getDocument(databaseId, rafflesCollectionId, id)
        return {
          id: doc.$id,
          participants: doc.participants as string[],
          winners: doc.winners as string[],
          drawnAt: doc.drawnAt as string,
          hash: doc.hash as string,
        }
      } catch (error) {
        // O Appwrite responde com code 404 quando o documento não existe.
        if ((error as { code?: number }).code === 404) return null
        throw error
      }
    },
  }
}

/** Grava um sorteio imutável e devolve o id do documento. */
export async function createShare(
  record: RaffleRecord,
  store?: RaffleStore,
): Promise<string> {
  try {
    const target = store ?? (await createAppwriteStore())
    const hash = await computeHash(record)
    return await target.create({ ...record, hash })
  } catch (error) {
    throw toShareError(error)
  }
}

/** Lê um sorteio compartilhado e confere se o hash ainda bate. */
export async function loadShare(
  id: string,
  store?: RaffleStore,
): Promise<{ raffle: StoredRaffle; verified: boolean }> {
  try {
    const source = store ?? (await createAppwriteStore())
    const raffle = await source.get(id)
    if (!raffle) throw new ShareError('NOT_FOUND', 'Sorteio não encontrado.')
    return { raffle, verified: await verifyRecord(raffle) }
  } catch (error) {
    throw toShareError(error)
  }
}
```

```ts
import { computed, ref } from 'vue'
import { drawWinners, type RandomInt } from '../lib/draw'
import { parseNames, removeNames, validateNames } from '../lib/names'

export interface Round {
  id: number
  drawnAt: string
  /** Lista usada no sorteio (antes da remoção dos vencedores, se houver). */
  participants: string[]
  winners: string[]
}

/** Estado e ações da tela do sorteador. A fonte de aleatoriedade é injetável para testes. */
export function useRaffle(randomInt?: RandomInt) {
  const rawInput = ref('')
  const winnerCount = ref(1)
  const noRepeat = ref(false)
  const history = ref<Round[]>([])
  const currentRound = ref<Round | null>(null)
  let nextId = 1

  const parsed = computed(() => parseNames(rawInput.value))

  /** Mensagem em português do que impede o sorteio agora, ou null se está tudo certo. */
  const drawError = computed<string | null>(() => {
    const inputError = validateNames(parsed.value)
    if (inputError) return inputError
    if (!Number.isInteger(winnerCount.value) || winnerCount.value < 1) {
      return 'Informe ao menos 1 vencedor.'
    }
    if (winnerCount.value > parsed.value.names.length) {
      return `Restam apenas ${parsed.value.names.length} nomes para sortear.`
    }
    return null
  })

  const canDraw = computed(() => drawError.value === null)

  /** Realiza um sorteio. Devolve a rodada, ou null se não for possível sortear. */
  function draw(): Round | null {
    if (drawError.value) return null

    const participants = [...parsed.value.names]
    const winners = drawWinners(participants, winnerCount.value, randomInt)
    const round: Round = {
      id: nextId++,
      drawnAt: new Date().toISOString(),
      participants,
      winners,
    }

    history.value.unshift(round)
    currentRound.value = round
    if (noRepeat.value) rawInput.value = removeNames(rawInput.value, winners)
    return round
  }

  function clearHistory() {
    history.value = []
  }

  return { rawInput, winnerCount, noRepeat, history, currentRound, parsed, drawError, canDraw, draw, clearHistory }
}
```

```vue
const props = defineProps<{ names: string[]; winners: string[]; durationMs?: number }>()
const emit = defineEmits<{ done: [] }>()

const displayed = ref<string[]>([])
const revealed = ref(false)
let intervalId: ReturnType<typeof setInterval> | undefined
let timeoutId: ReturnType<typeof setTimeout> | undefined

function stop() {
  clearInterval(intervalId)
  clearTimeout(timeoutId)
}

/** Mostra o resultado final e avisa quem escutou. O resultado já estava definido antes da animação. */
function finish() {
  stop()
  displayed.value = [...props.winners]
  revealed.value = true
  emit('done')
}

function start() {
  stop()
  revealed.value = false
  if (window.matchMedia('(prefers-reduced-motion: reduce)').matches) {
    finish()
    return
  }
  // Math.random é suficiente aqui: os nomes embaralhados são só efeito visual.

    displayed.value = props.winners.map(
      () => props.names[Math.floor(Math.random() * props.names.length)] ?? '',
    )
  }, 80)
  timeoutId = setTimeout(finish, props.durationMs ?? 2000)
}

watch(() => props.winners, start, { immediate: true })
onBeforeUnmount(stop)
```

```vue
import { createShare, ShareError } from './lib/share'

const { rawInput, winnerCount, noRepeat, history, currentRound, drawError, canDraw, draw, clearHistory } = useRaffle()

const animating = ref(false)
const sharing = ref(false)
const shareUrl = ref<string | null>(null)
const copied = ref(false)

// Cada nova rodada invalida o link anterior.
watch(currentRound, () => {
  shareUrl.value = null
  copied.value = false
})

function onDraw() {
  const round = draw()
  animating.value = round !== null
}

async function onShare() {
  if (!currentRound.value) return
  sharing.value = true
  try {
    const { participants, winners, drawnAt } = currentRound.value
    const id = await createShare({ participants, winners, drawnAt })
    shareUrl.value = `${window.location.origin}/raffle/r/${id}`
    toast.success('Link gerado!')
  } catch (error) {
    toast.error(error instanceof ShareError ? error.message : 'Não foi possível gerar o link.')
  } finally {
    sharing.value = false
  }
}

async function onCopy() {
  if (!shareUrl.value) return
  try {
    await navigator.clipboard.writeText(shareUrl.value)
    copied.value = true
    toast.success('Link copiado!')
  } catch {
    toast.error('Não foi possível copiar. Selecione o link e copie manualmente.')
  }
}
</script>
```

```vue
<script setup lang="ts">
import { AlertTriangle, ShieldCheck } from '@lucide/vue'
import { onMounted, ref } from 'vue'
import { RouterLink, useRoute } from 'vue-router'
import { Button } from '@/components/ui/button'
import { Card, CardContent, CardHeader, CardTitle } from '@/components/ui/card'
import { loadShare, ShareError, type StoredRaffle } from './lib/share'

type State = 'loading' | 'ready' | 'not-found' | 'error'

const route = useRoute()
const state = ref<State>('loading')
const raffle = ref<StoredRaffle | null>(null)
const verified = ref(false)
const errorMessage = ref('')

onMounted(async () => {
  try {
    const result = await loadShare(String(route.params.id))
    raffle.value = result.raffle
    verified.value = result.verified
    state.value = 'ready'
  } catch (error) {
    if (error instanceof ShareError && error.code === 'NOT_FOUND') {
      state.value = 'not-found'
    } else {
      errorMessage.value =
        error instanceof ShareError ? error.message : 'Algo deu errado ao abrir este sorteio.'
      state.value = 'error'
    }
  }
})

function formatDate(iso: string): string {
  return new Date(iso).toLocaleString('pt-BR', { dateStyle: 'long', timeStyle: 'short' })
}

      >
        <ShieldCheck class="mt-0.5 size-5 shrink-0 text-green-600" />
```

````markdown
# Canivete

Hub público de ferramentas. Vue 3 + Vite + TypeScript + Tailwind v4 + shadcn-vue + Appwrite (só onde necessário).

npm install

## Adicionar uma ferramenta

Crie `src/modules/<id>/manifest.ts` exportando um `ToolManifest` (ver `src/core/modules/types.ts`).
As rotas do módulo devem começar com `/<id>`. Nada no `core` precisa ser editado.

## Configurar o Appwrite (sorteador)

1. No console do Appwrite, crie um projeto e adicione uma plataforma **Web** com o domínio do site (e `localhost` para desenvolvimento).
2. Crie um banco de dados e uma coleção com id `raffles`.
3. Crie os atributos:

| Atributo | Tipo | Tamanho | Obrigatório | Array |
|---|---|---|---|---|
| `participants` | string | 100 | sim | sim |
| `winners` | string | 100 | sim | sim |
| `drawnAt` | datetime | | sim | não |
| `hash` | string | 64 | sim | não |

4. Permissões da coleção: **Read** e **Create** para `Any`. **Não** conceda Update nem Delete.
5. Preencha `.env.local` com `VITE_APPWRITE_ENDPOINT`, `VITE_APPWRITE_PROJECT_ID`, `VITE_APPWRITE_DATABASE_ID` e `VITE_APPWRITE_RAFFLES_COLLECTION_ID`.

## Hospedagem

O site usa rotas por histórico (`/raffle/r/abc`). A hospedagem precisa devolver `index.html` para qualquer rota desconhecida (fallback de SPA).
````
